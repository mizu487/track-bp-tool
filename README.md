# Music BP Tool — GitHub Pages 发布包

本目录中的文件可以直接放入 GitHub 仓库根目录并通过 GitHub Pages 发布。

## 发布

1. 将本目录内的全部文件上传到仓库的默认分支根目录。
2. 打开仓库 `Settings → Pages`。
3. 在 `Build and deployment` 中选择 `Deploy from a branch`。
4. 选择默认分支和 `/(root)`，然后保存。
5. 等待 GitHub Pages 显示发布地址。

## 迁移原工作台数据

1. 在原网站进入 `referee.html`，使用密码 `1104`。
2. 在“数据迁移”中选择“导出完整备份”。
3. 打开 GitHub Pages 版本的 `referee.html`。
4. 选择“导入完整备份”，确认数据数量后导入。
5. 核对选手、头像、曲库、封面、赛程和比赛结果。

备份文件包含赛事及选手数据，请妥善保管，不要发送给无关人员。迁移时请先结束正在进行的 BP 房间；实时房间号和连接状态不会写入备份。
